# Bazar.com

Part 1 distributed bookstore project for Distributed and Operating Systems.

Current status: catalog service and catalog Docker support are implemented. Front-end and order services are planned next.

See `docs/RUN.md` for run instructions and `docs/API_CONTRACT.md` for the API contract.

A `docker-compose.lab2.yml` skeleton exists for future Lab 2 replica and caching work. Lab 2 behavior is not implemented yet.
